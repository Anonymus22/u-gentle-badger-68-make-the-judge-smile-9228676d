## Entry

> This morning the stray cat who always ignores me wandered up, headbutted my ankle, then claimed my warm seat like she'd paid rent all along.

## Description

A single warm line about a small good thing that happened today: a stray cat
that has never once acknowledged me finally chose me — with a headbutt, and
then immediately evicted me from my own warm seat. The program writes this
one line, deterministically, to `entry.txt`.

## Run

Requires Node.js 22 (standard library only, no dependencies).

```sh
MAKEFUN_OUTPUT_DIR=/path/to/output node main.ts
```

This writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(defaulting to `/output/entry.txt` when the variable is unset).
